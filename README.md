# Game-001-Design

Game-001の企画・仕様書を管理するリポジトリです。

## 管理対象

- ゲーム企画書
- ゲームデザインドキュメント
- ゲームシステム仕様
- キャラクターおよびアイテム仕様
- ゲームバランス
- レベル設計
- UI仕様
- 議事録

## ディレクトリ構成（予定）

- Planning/：企画書
- Specifications/：仕様書
- Balancing/：バランス設計資料
- MeetingNotes/：議事録
- References/：参考資料
- Templates/：仕様書テンプレート

## 運用方針

仕様書は原則Markdownで管理します。
制作依頼やタスクの進捗はGitHub IssuesおよびProjectsで管理します。

## 管理担当

Game-001-Planners

## 開発状況

開発基盤構築中。

## 利用方法

- 作業は `main` からブランチを作成し、Pull Requestで提案してください。
- タスクはGitHub Issues / Projectsで管理します。
- 変更の責務: Game-001-Design。担当Team: `Game-001-Planners`。
- 依存関係や開発状況は [DevelopmentDocs](https://github.com/FUREQ-DEVELOP/DevelopmentDocs) を参照してください。
